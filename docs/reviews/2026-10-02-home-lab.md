# 居家練習進度審查與補強（2026-10-02）

後續更新：本文件保留前一輪 225／301 驗證及當時待辦；串接電流、復原與含電容保護已於 [電流與復原補強](2026-10-02-current-undo-protection.md) 按明示範圍完成。

本輪依使用者最新方向：先完善四台儀器的功能介面，供在家重做課堂實驗，再逐步擴充元件。以 GitHub 已合併版本 `6ad3ed7` 為基準，未新增電路元件、學校管理或帳號系統。附帶文件中的歷史指令只作審查資料。

## 判斷

已有四台儀器的核心操作，以及電阻／RC 接線、分壓、濾波與充放電的練習能力。原版 175 項模型、265 項 UI 都通過；追加反例仍找到操作問題，所以不以測試數量或未支援按鍵比例換算功能完成百分比。

本輪補強後適合目前已支援的 R／RC 居家練習範圍。全機原廠功能與校機實測一致性仍未完成驗證。

## 修正

| 問題 | 原例及處理 |
|---|---|
| AFG 游標落到看不到的位數 | 1 kHz 編輯時連按左鍵兩次，底線消失且旋鈕一格跳到 11 kHz。現在游標限制在實際顯示數字；切單位、進位後同步限制，原例一格成 2 kHz。 |
| TDS 恢復採集補抓已錯過的事件 | Normal 模式 Stop／關機期間電容已穿越觸發位準，恢復後卻補抓停機期間的舊上升沿。清除舊觸發搜尋與 Single 起點，恢復時從現在開始等待；恢復後的新事件仍可擷取。 |
| TDS 極低頻 AutoSet 崩潰 | 1 mHz 沒有足夠時基容納兩個週期，索引變成 −1。改用最大 50 s/div，清楚提示畫面不足兩個週期。 |
| TDS AutoSet 產生無法載入的配置 | 0.5 V/div、Position ±50 div 合法；AutoSet 曾選 0.2 V/div 卻留下超過新刻度限制的 Position。選檔時一併檢查位置範圍，不滿足則使用已有歸零後備規則；沒有放寬存檔驗證。 |
| GPE Set View 側欄逾時不更新 | LCD 到期已切回讀回，側欄仍寫 Set View 中。定時同步計時狀態，結束後再刷新一次。 |

## 實驗保存

- 自動保存同一瀏覽器中的四機已提交設定、固定 RC 板與麵包板的元件／接線、探棒倍率、分頁與縮放。
- 上方「匯出實驗／載入實驗」使用版本化 JSON；不同瀏覽器或電腦可手動帶走檔案。自動保存失敗時明示使用匯出，儀器仍可操作。
- 不保存未提交數字、電容電荷、舊波形紀錄、操作歷史；載入會明示重新開始模擬。Stop 使用新配置採集後凍結，Single 重新等待。
- 載入先檢查版本、欄位、量程、聯合限制、孔位／佔用，再在獨立模型預演；失敗不部分替換現況。拒絕超過 1 MB 的檔案。
- 自動保存只讀設定，不讀時鐘、不求解、不觸發新採集。

## 驗證

- 最終模型：225／225；控制矩陣 190 列通過，12／12 刻意破壞的矩陣案例被拒絕。
- 最終真 UI：301／301（原有 265 項，加保存／載入 16 項及儀器補強 20 項），沒有瀏覽器程式錯誤。新增 AutoSet 位置反例也以真拖曳旋鈕、匯出、嚴格驗證和檔案載入完整通過。
- 獨立保存／載入複核：發現 AutoSet 位置限制問題，修後回測正負原例，TDS＋Session 97／97 通過，配置往返相等、clock／source callbacks 保留，指定範圍沒有殘留阻擋。
- 真 UI 使用實際滑鼠、鍵盤、選單及檔案選擇；`__eess` 僅讀。檢查重新整理、兩種板子、四機設定、匯出與載入、損壞／未知版本／超大檔案拒絕，以及禁止瀏覽器儲存時仍能操作並匯出。
- 原始手冊 PDF 未放在此 checkout 的 reference；本輪規格比對依 docs/data 的既有原廠引文，不聲稱重新逐頁查核原 PDF 或實機校準。

## 下一階段仍需補強

目前主要限制仍是實驗台 DMM 串接電流量測、麵包板復原／重做，以及部分尚未支援的儀器功能。AFG／GPE 共同驅動含電容網路的完整週期保護、探棒電容及真機誤差等已知近似也仍保留。這些限制不以新存檔功能掩蓋；元件仍只有 R、C、跳線。
