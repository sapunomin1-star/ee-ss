# 四台儀器第二輪驗收修正（2026-10-04）

接續 `fb6bc83` 功能補強版，這輪以實際操作產生反例，再修正模型與跨儀器互動。離線頁面標示「2026.10.04 驗收修正版」。

## 量測修正

- 示波器 Single／Normal 收到觸發後，等待真實後觸發時間窗結束才發布完整 2500 點。採集期間關電、拔探棒或改輸出，按當時的電路歷史取樣。Auto、Scan、XY 不再取用尚未發生的波形；Average、Limit、Logging 依已完成紀錄運作。
- 示波器歷史取樣保留 AC 耦合與 BW Limit 的因果濾波。實驗台提供原始分段、週期穩態及 RC 模態資訊，讓濾波能辨別電路切換時間，避免把目前的直流電壓畫到先前未開電的時段。實體探棒倍率也隨歷史保存，1×／10× 切換不改寫舊的 BNC 電壓。
- 5 ns/div 下的慢速 AC 充電也能依實際交越完成觸發搜尋；使用可證明的斜率界排除不可能區間，非線性或缺少資訊的訊號保持保守搜尋。叫回 Single 設定會清除上一筆完成旗標。
- 電表 Single 使用整個已完成的量測窗；之後改接線、改 Sense 參考、換元件或關輸出，不會覆寫舊讀值。Sense 檢查整窗的 ±12 V 邊界；當窗內接線不完整或計算不可用時不製造數值。停止後量程與實際輸入阻抗保持一致。
- 電表背景持續採集，切到其他儀器面板仍可累積統計、Limits、Probe Hold。非有限讀值不再使 LCD 崩潰；更改溫度感測設定重新採集，單位與 Null 切換會重建 Probe Hold 的穩定判定。
- 電表 CSV 的數值與單位統一採基礎單位；統計與直方圖明示相同單位，Probe Hold 的格式化文字則保留對應的顯示前綴。避免 0.01234 A 被匯出成 0.01234 mA，或 1000 Hz 被標成 1000 kHz。
- AFG 切換波形重新驗證頻率、振幅與偏移限制；ARB 垂直範圍移動保持非零跨度；Manual Burst 的方波起始相位按真實觸發時間計算；Tracking 不會挪用另一種模式先前的 Manual 觸發時間。

## 操作與相容性

示波器 Save/Recall 的 File 模式可下載及載入本模擬器的 Setup JSON。載入前沿用內部 Setup 的完整驗證；損壞或不相容檔案保持原設定，輸入接線與其他儀器不變。這是瀏覽器檔案操作，並非 Tektronix 原廠 SET 格式。

電表新增 Display 的 Digit Mask、Bar Scale 與支援的第二量測顯示。主值的統計保留完整精度。第二量測以相容訊號計算；DC 主量測搭配 AC 次值採交錯更新的教學時序，保留主功能的輸入阻抗模型。

完整實驗存檔與儀器記憶保留新增設定；舊版 DMM User Defined 記憶會補入新顯示選項的預設值。重新載入會清除未完成示波器採集及第二量測快取，重新開始時間軸。
