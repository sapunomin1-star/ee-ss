**實驗台與電表的修法**
- 電路：每個取樣區間內用解析式 a＋b·s＋c·e^(−s/τ)，有效值、平均、逐點取值都照它算，不靠取樣點。窄脈衝 ACV＝16.33 mV（解析值）。

- 暫態：只有一顆電容，電壓＝新週期穩態＋δ·e^(−t/τ)；電路一變（接線、R/C、AFG 設定、電表功能），就從變化前一刻的電容電壓接續。關 OUTPUT 後電容只經儀器輸入電阻放電（100 kΩ／10 µF 時 τ≈33 s）。τ 短於 50 ms 的暫態示波器直接顯示穩態（一眨眼就結束）。

### 7c5ccf4 複核後修正（8 項，都先重現）
